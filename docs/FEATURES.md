# Особине MuteSpotifyAds

## Преглед особина

### Мутирање реклама (Mute Ads)

Основна функционалност апликације. Кад Spotify почне да пушта рекламу:
1. Апликација детектује рекламу провјером URL-а тренутне нумере (`spotify:ad` префикс)
2. Сачува тренутну јачину звука корисника
3. Постави јачину звука на 0
4. Кад реклама заврши, врати јачину на сачувану вриједност
5. Ако је корисник ручно промијенио јачину током рекламе (нпр. unmute-овао), апликација поштује ту промјену

Status bar индикатори:
- ☀︎ (сунце) -- нормално пуштање музике
- ☂︎ (кишобран) -- реклама детектована, Spotify утишан

### Restart to Skip Ads (Рестарт за прескакање реклама)

Опционална функционалност. Кад се детектује реклама, умјесто мутирања:
1. Затвори Spotify преко AppleScript-а
2. Поново покрени Spotify у позадини
3. Аутоматски настави пуштање музике (са retry логиком)

**Укључивање**: Status bar мени → `◎ Restart to skip ads`

### Endless Private Session (Бесконачна приватна сесија)

Осигурава да је Spotify приватна сесија увијек укључена. Сваки пут кад се нумера промијени, апликација провјерава и поново укључује приватну сесију ако је искључена.

**Укључивање**: Status bar мени → `∞ Private session`

**Захтијева додатне привилегије**:
1. System Preferences → Security & Privacy → Privacy → Accessibility → укључити MuteSpotifyAds
2. System Preferences → Security & Privacy → Privacy → Automation → укључити Spotify и System Events за MuteSpotifyAds

**Механизам**: Преко System Events AppleScript-а кликне на "Private Session" у Spotify менију ако није чекирано.

### Song Log (Лог нумера)

Логује информације о свакој нумери коју слушате у CSV фајл. Садржи сљедеће колоне:

| Колона | Опис |
|---|---|
| name | Назив нумере |
| artist | Извођач |
| album | Албум |
| disc number | Број диска |
| duration | Трајање |
| played count | Број пуштања |
| track number | Број нумере на албуму |
| popularity | Популарност |
| id | Spotify ID |
| artwork url | URL artwork-а |
| album artist | Артист албума |
| spotify url | Spotify URL |
| date | Датум и вријеме пуштања |

**Укључивање**: Status bar мени → `Song log` → одабрати локацију за CSV фајл.

### Auto-start Spotify

Аутоматски покреће Spotify десктоп клијент кад се MuteSpotifyAds покрене. Подразумевано укључено.

**Укључивање/искључивање**: Status bar мени → `Start Spotify`

### Нотификације

Приказује macOS нотификацију кад се реклама детектује. Подразумевано укључено.

**Укључивање/искључивање**: Status bar мени → `Notifications`

## Status bar мени

Мени апликације се отвара кликом на ☀︎/☂︎ икону у macOS status bar-у (при врху екрана). Садржи:

| Ставка менија | Опис |
|---|---|
| MuteSpotifyAds vX.X.X | Назив и верзија апликације (информативно) |
| ∞ Private session | Укљ/искљ бесконачне приватне сесије |
| ◎ Restart to skip ads | Укљ/искљ рестартовања за прескакање |
| Start Spotify | Укљ/искљ аутоматског покретања Spotify-ја |
| Notifications | Укљ/искљ нотификација |
| Song log | Укљ/искљ логовања нумера (бира се путања фајла) |
| Project website | Отвара GitHub страницу пројекта |
| Report a bug | Отвара GitHub Issues страницу |
| License | Отвара GPL v3 лиценцу |
| Author | Отвара web страницу аутора |
| Quit | Затвара MuteSpotifyAds (Spotify остаје покренут) |
| Quit with Spotify | Затвара и MuteSpotifyAds и Spotify |

## Пречице преко тастатуре

Апликација нема сопствене глобалне пречице. Сва интеракција је преко status bar менија.

## Аутоматизације

- **Аутоматско покретање при старту система**: Корисник може додати MuteSpotifyAds у Login Items (System Preferences → Users & Groups → Login Items) да се апликација аутоматски покреће при пријави.
- **Аутоматско покретање Spotify-ја**: Кад је "Start Spotify" укључено, Spotify се аутоматски покреће заједно са MuteSpotifyAds.
- **Аутоматско гашење**: Кад корисник затвори Spotify, MuteSpotifyAds се аутоматски гаси (ако је "Start Spotify" укључено).
- **Памћење подешавања**: Сва подешавања се чувају у UserDefaults и аутоматски се враћају при поновном покретању.
